# 文件夹命名规则规范

### 命名格式：
`MM-DD-Name-Gender(F/M)-#n`

### 字段说明：
| 字段         | 格式要求                     | 示例         | 说明                                 |
|--------------|-----------------------------|--------------|--------------------------------------|
| **MM**       | 两位月份 (01-12)            | `08`         | 8月                                  |
| **DD**       | 两位日期 (01-31)            | `13`         | 13日                                 |
| **Name**     | 英文名（首字母大写）         | `Alice`      | 名称中**不可包含空格或连字符**       |
| **Gender**   | 单字母标识 (F/M)             | `F`          | F=女性, M=男性，**不带括号**         |
| **#n**       | `#`+序号数字                 | `#1`         | 当天的文件夹序号（从1开始）          |
